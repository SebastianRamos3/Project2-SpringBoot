# Welcome to our basketball betting app 🏀
Names: Senen Bagos, Felipe Lopez, Sebastian Ramos, Liliana Saavedra

This project is broken down by its front end and backend repos, where the front end demands certain API functionalities and the back-end has to meet those demands. We will be recreating the Spring Boot REST API to meet these demands.

The persistence layer consists of a database we will be creating and connecting to, hosted by Heroku.

The requirements for this project are the following:
- Must use Oauth2
- Must use at least the following REST verbs
   - GET
   - POST
   - PUT
   - DELETE
- Must use persistent storage
-----------------------------
- Use a Github Project
- All merges to main must be made via a pull request
- All pull reuests MUST be reviewed
   -must be reviewed by at least 2 teammates who are not the developer
- All PRs must be associated with at least one issue

Our team has decided to use AWS and Heroku to use for our database.

This is an [Expo](https://expo.dev) project created with [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
    npx expo start
   ```

In the output, you'll find options to open the app in a

- [development build](https://docs.expo.dev/develop/development-builds/introduction/)
- [Android emulator](https://docs.expo.dev/workflow/android-studio-emulator/)
- [iOS simulator](https://docs.expo.dev/workflow/ios-simulator/)
- [Expo Go](https://expo.dev/go)
